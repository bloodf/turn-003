# Assets

Everything is generated by `forge/build.sh`. Nothing is downloaded, so nothing carries someone else's licence.

- **58 materials** (`materials.py`): a height field is synthesised per material (stone courses, planks, thatch, cobble, bark, mail...), then colour, normal, roughness and occlusion are derived from it. All seamless, 1024 and 512 px.
- **203 models** (`props.py` on `kit.py`): Blender primitives, bevels, voxel sculpting; occlusion ray traced into the vertices; a low-detail twin of each. 165k triangles in 3.2 MB.
- **48 creatures** (`chars.py`): 12 heroes, 6 townsfolk, 18 humanoid foes, 12 beasts. Sculpted, skinned, 240k triangles in 5.4 MB.
- **Foliage, webs** (`cutouts.py`). **Interface furniture** (`ui_render.py`, Cycles): iron-and-gilt frame, oak plaques, wax seal, d20.

## Adding a model
Write a function in `forge/props.py`:
```python
@asset('furnish', tags=['store'], col='box')      # category, search tags, collider: box | circle | none
def my_crate(a):
    a.box(.8, .8, .7, mat='planks')                # any of the 58 materials
    a.rivets([(0, -.41, .4)])
    a.lamp(0, 0, 1, (1, .6, .3), 1, 8)             # optional: it gives light
```
Run `forge/build.sh`, then `scripts/capture/thumbs.cjs` with the dev server up for its picture. It appears in the editor's library.
